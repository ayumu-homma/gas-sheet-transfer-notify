# シート構成

このファイルは、スプレッドシートを公開しなくても、同じ列構成を再現できるようにしたものです。実在の個人情報は入れていません。

## シート「受付」

| 列 | ヘッダー（1行目をこの文言どおりにする） | 内容 |
| --- | --- | --- |
| A | タイムスタンプ | 行が増えた日時。空ならスクリプトが補います |
| B | 名前（ダミー） | 架空の名前 |
| C | 内容 | 依頼内容のダミー文 |
| D | 状態 | `要対応` / `転記済` / `対応不要` など |
| E | メール（ダミー） | 参考用。通知の宛先には使いません |

サンプル行は `samples/uketsuke.csv` と同じです。

- 2行目: 状態が `要対応`。処理対象になります。
- 3行目: 状態が `対応不要`。処理しません。

フォーム連携にする場合も、フォームの質問名を上のヘッダーと一致させてください。フォームに「状態」が無いときは、送信された行の状態が空になります。その場合だけ、スクリプトは `要対応` とみなします。

## シート「処理済み」

ヘッダーは「受付」と同じです。処理が成功すると、対象行と同じ内容が最終行に追加され、状態は `転記済` になります。期待される例は `samples/processed.csv` です。

## 通知メール

宛先は、行の「メール（ダミー）」ではなく、スクリプト プロパティ `NOTIFY_TO`（自分のテスト用アドレス）です。行のメールは本文に参考として載せるだけです。`example.com` などのダミーアドレスへ送らないでください。

件名: `【サンプル】新しい要対応行を転記しました`

本文の構成:

- 公開サンプルであることの一文
- 発生元（formSubmit / edit / manualTest）
- タイムスタンプ、名前、内容、ダミーメール
